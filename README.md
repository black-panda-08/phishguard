# PhishGuard

PhishGuard is a web-based phishing detection system that uses machine learning to identify suspicious URLs. It extracts URL-based security features, sends them to a Flask API, and predicts whether a link is safe or phishing using a trained Random Forest classifier.

## Features

- Real-time URL phishing detection
- Flask backend API
- Random Forest machine learning model
- URL feature extraction
- Interactive HTML frontend
- Confidence score for predictions
